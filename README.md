# Sistemas Inteligentes I: Práctica de Búsqueda No Informada (BFS y DFS)
Este repositorio contiene la implementación conjunta de los algoritmos de Búsqueda en Anchura (BFS) y Búsqueda en Profundidad (DFS) aplicada a problemas de exploración de grafos y resolución de laberintos. El proyecto abarca desde el modelado teórico del espacio de estados hasta la visualización y análisis comparativo del desempeño de cada estrategia.

# Descripción del Proyecto
El objetivo principal de esta práctica es implementar y evaluar algoritmos de búsqueda no informada, los cuales exploran el espacio de estados sin disponer de una función heurística que estime la distancia hacia el objetivo.

+ Modelado Teórico: Definición formal del espacio de estados, operadores de transición y funciones objetivo.

+ Implementación Algorítmica: Creación de las estructuras de datos y funciones para BFS y DFS en Python.

+ Casos de Aplicación: Pruebas controladas sobre grafos no ponderados y matrices que representan laberintos con obstáculos.   

+ Análisis de Rendimiento: Comparación en términos de longitud del camino, número de nodos explorados y uso de memoria.
